# AGNES Image 2.5 中文提示词 Skill

专为 AGNES Image 2.5 设计的中文 AI 生图提示词技能包，帮助大语言模型和 AI 智能体生成、优化、改写和诊断专业图像提示词。

## 项目介绍

本项目将 AGNES Image 2.5 的提示词创作流程整理为一套可复用的 Skill。

它不是生图软件，也不是 API 接口工具，而是专门用于提升 AI 智能体提示词创作能力的技能包。

## 核心功能

- **文生图提示词：** 根据文字需求生成专业生图提示词。
- **图生图提示词：** 优化图片修改、风格转换和场景调整指令。
- **多图融合：** 设计多张参考图的融合与组合提示词。
- **提示词优化：** 改进描述准确性、细节表现和画面结构。
- **提示词诊断：** 分析提示词中的冲突、歧义和表达缺陷。
- **商业视觉创作：** 支持产品摄影、电商主图、海报、人物肖像和场景设计。
- **角色一致性：** 优化角色外观、服装和视觉特征的统一描述。

## 安装与使用

### 方法一：直接使用

下载本仓库中的 `SKILL.md`，将文件提供给支持文件上传的 AI 大语言模型或智能体，并要求其读取和遵循技能规则。

### 方法二：接入支持 Agent Skills 的智能体

将本项目放入智能体支持的 Skills 技能目录中，按照对应平台的技能加载规则启用。

具体目录和加载方式以所使用的平台为准。

## 使用示例

向加载了本 Skill 的 AI 智能体发送以下指令：

- 帮我生成一张高端商业产品摄影提示词。
- 分析这张图片，并反推出专业中文生图提示词。
- 将这段提示词优化成电影级视觉效果。
- 保留人物面部特征，只修改服装和背景。
- 将多张参考图片融合成一张完整画面。
