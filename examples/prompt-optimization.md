# 提示词优化示例

## 任务

将简单、模糊的自然语言描述优化为专业生图提示词。

## 原始提示词

一个漂亮的女生，站在海边，夕阳很好看，照片要高级一点。

## 问题分析

原始提示词存在以下问题：

1. 人物外貌描述不明确。
2. 缺少人物姿态和服装信息。
3. 海边环境缺少具体细节。
4. 没有明确摄影风格和构图。
5. 光线和色彩描述过于笼统。
6. 缺少画面质量与真实感要求。

## 优化后的提示词

一位年轻女性站在宁静的海岸线上，身穿简约优雅的浅色长裙，长发被海风轻轻吹动，身体自然侧向镜头，神情放松，目光望向远方。

远处是辽阔的海平面，海浪轻柔地拍打沙滩，天空呈现夕阳时分的暖金色渐变，海面反射细腻的金色光芒。

采用高端时尚人像摄影风格，电影级自然光照，夕阳逆光勾勒人物轮廓，人物面部保留自然细节，背景具有柔和景深。

采用三分法构图，人物位于画面视觉中心偏侧位置，保留适当环境空间，画面层次分明，色彩自然协调，呈现高级、浪漫、真实的电影摄影质感。

## 优化结果

- 主体更加明确
- 人物外观和姿态更加具体
- 环境具有空间层次
- 光照和色彩更加清晰
- 摄影风格更加明确
- 构图和视觉重点更加合理

## 优化原则

优化提示词时，不应简单堆砌形容词，而应优先补足主体、场景、空间关系、光照、构图和风格等关键信息。

## 说明

本示例展示 Skill 如何诊断普通提示词的问题，并将其转换为结构完整、视觉表达明确的专业提示词。
